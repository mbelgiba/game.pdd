# Дорога домой — игра про ПДД (дипломный проект) v0.4
Запуск (без sudo):  cd ~/game.pdd && python3 -m http.server 8000   → http://localhost:8000
Управление: WASD/стрелки, Пробел — ручник, C/Q/E/L — круиз, P — телефон, M — карта, H — справочник, Esc — пауза.
Структура: src/ — код, data/story.json — сюжет и NPC, data/handbook.json — справочник.
